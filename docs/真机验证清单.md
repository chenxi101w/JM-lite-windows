# 真机验证清单（v1.0.0）

> 双击 `D:\Game\JMComicLite\JMComicLite.exe`（或解压便携 zip 运行），按下列步骤走一遍。
> 格式：操作 → 期望结果。打勾即通过。

## 启动与基础
- [ ] **冷启动**：双击 exe → 窗口打开显示搜索页，无报错
- [ ] **UserData 自动建**：exe 同级出现 `UserData/`（core / DownloadedComics / TempCache / webview_data / .app_url）
- [ ] **关窗重开**：再次启动正常，上次的设置修改仍保留

## 搜索
- [ ] **关键词搜索**：输入任意关键词 → 出现结果卡片（封面/标题/作者/标签）
- [ ] **同义词扩展**：搜「爆乳」也能命中「巨乳」系作品（硬需求，重点回归）
- [ ] **纯数字 ID**：输入 JM 号 → 直达该作品卡片
- [ ] **标签 / 作者搜索**：切换搜索范围分段控件后搜索正常
- [ ] **详情模态**：点卡片 → 显示详情（封面/信息/标签/简介）；Esc 或点空白处关闭
- [ ] **黑名单过滤**：设置页添加屏蔽作者 → 再搜索该作者，结果被过滤不出现

## 下载
- [ ] **单本下载**：详情模态点「下载」→ 提示已开始 → 完成后提示下载完成
- [ ] **批量下载**：下载页输入多个 JM 号 → 多个任务启动，并发数不超过设置上限
- [ ] **进度实时**：进行中列表进度条推进；完成后自动移出、进入历史
- [ ] **历史管理**：单条删除 / 清空历史均生效

## 阅读
- [ ] **进入阅读器**：书架点卡片 → 阅读器打开该漫画
- [ ] **翻页**：按钮 / 键盘 ←→ 翻页正常；滚轮以光标为中心缩放；Esc 返回
- [ ] **进度续读**：翻到第 N 页 → 返回 → 再次进入 → 从第 N 页继续（重点回归）
- [ ] **多章切换**：多章漫画「上一章 / 下一章」切换正常
- [ ] **读完标记**：翻到最后一页 → 提示「已标记读完」，书架卡片出现已读完角标

## 书架
- [ ] **列表与封面**：书架显示已下载漫画与本地封面
- [ ] **收藏**：点 ★ 切换收藏；切到「收藏」视图只见收藏项
- [ ] **拖拽归类**：新建分类 → 把漫画拖到分类上 → 归类生效；「未归类」视图正确
- [ ] **重命名 / 删除分类**：重命名生效；删除非空分类弹出「去向选择」（未归类/其他分类），确认后漫画转移
- [ ] **删除本地**：点 🗑 确认后漫画从书架消失，本地文件删除

## 订阅与设置
- [ ] **订阅作者**：设置页添加作者 → 出现在订阅列表
- [ ] **手动巡检**：「立即巡检」返回统计（检查 N 位作者 / 新增 N 条）
- [ ] **新作记录**：巡检发现的新作显示在「新作记录」，可「全部已读 / 清空」
- [ ] **黑名单管理**：作者 / 作品 / 标签三类屏蔽项的添加、删除均生效
- [ ] **设置保存**：改并发数 / 画质 / 主题 / 代理 → 保存 → 重启后仍生效
- [ ] **主题切换**：切暗色界面立即变暗；选「跟随系统」随系统明暗切换

## 边界与回归
- [ ] **GBK 特殊字符**：下载含特殊字符标题（如 ♡）的作品不崩溃（UTF-8 强制生效）
- [ ] **网络异常**：断网或站点不可达时，搜索给出友好提示，不白屏
- [ ] **与旧版并行**：旧版 JMComicReader（端口 28888）与轻量版（28889）同时运行互不影响

# v2.0.0 新增（对齐手机端 + UI 重做）

## 云同步
- [ ] 设置 → 书架 → 云同步：开关可开、服务器地址与密钥可正常保存（密钥显示遮罩）
- [ ] 点「立即同步」→ 显示结果（拉回 N · 推上 N，服务器新增 N）；再次点击结果幂等（服务器新增 0）
- [ ] 打开一本漫画详情 / 阅读器后，书架账本数 +1（可再同步验证推上数变化）
- [ ] 关闭同步开关后，重启应用不再自动同步（自动同步需开启 + 距上次成功 ≥6h）

## 批量删除（书架）
- [ ] 点「选择」进多选：卡片出现勾选圈；点卡片切换选中（不再进阅读器）
- [ ] 「全选 / 未读 / 已读」一键勾选正确（未读 = 从没打开过阅读器的）
- [ ] 「删除所选」→ 确认 → 提示「已删除 X/Y 本（移入回收站）」，列表刷新

## 回收站

- [ ] 单本「删除」→ 移入回收站；回收站里显示封面 + 「可重新下载」

- [ ] 看完整本 → 回收站出现该本（状态「宽限中 · 剩 N 天」）；期间重新阅读自动续期
- [ ] 「恢复」= 清掉回收标记；「彻底删除」= 账本/标记/封面全清（二次确认）
