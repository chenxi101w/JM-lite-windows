# assets/screenshots/README.md 截图放置目录

仓库 README「📸 预览」小节的图片放这里。**放好图后，去 README 把那段的 HTML 注释取消即可显示。**

## 命名与内容（README 已按此引用）

| 文件名 | 内容 |
|---|---|
| `home.png` | 主页 · 书架 |
| `search.png` | 搜索 |
| `reader.png` | 阅读器 · 连排/缩放 |
| `library.png` | 分类树 · 回收站 |

## 规格建议

- **静图**：PNG，宽约 720px，单张 < 500KB（GitHub 渲染快）
- **动图**：GIF，< 10MB、帧数别太多（README 里用 `<img src="assets/screenshots/xxx.gif" width="720"/>` 同样有效）
- 录动图可用 ScreenToGif / LICEcap，截 3-5 秒一个动作即可

## ⚠️ 隐私提醒

这些图会进**公开仓库**。截图书架/下载页时，注意别带出不想公开的内容（自己的收藏、订阅、本地路径等）—— 可以用测试数据或空账号状态截。
